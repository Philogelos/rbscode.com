Teacher Answer

Completed HTML and CSS

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Mini Castle</title>

    <style>
        body {
            font-family: cursive;
            background-color: lightgray;
        }

        h1 {
            text-align: center;
        }

        #scene {
            width: 500px;
            height: 350px;
            background-color: skyblue;
            position: relative;
            margin: auto;
        }

        #grass {
            width: 500px;
            height: 90px;
            background-color: green;
            position: absolute;
            bottom: 0;
            left: 0;
        }

        #castle {
            width: 180px;
            height: 150px;
            background-color: gray;
            position: absolute;
            bottom: 90px;
            left: 160px;
        }

        #door {
            width: 50px;
            height: 70px;
            background-color: brown;
            position: absolute;
            bottom: 90px;
            left: 225px;
        }

        #flagPole {
            width: 8px;
            height: 100px;
            background-color: black;
            position: absolute;
            bottom: 240px;
            left: 246px;
        }

        #flag {
            width: 70px;
            height: 40px;
            background-color: purple;
            position: absolute;
            top: 10px;
            left: 254px;
        }
    </style>
</head>

<body>

    <h1>Mini Castle</h1>

    <div id="scene">
        <div id="grass"></div>
        <div id="castle"></div>
        <div id="door"></div>
        <div id="flagPole"></div>
        <div id="flag"></div>
    </div>

</body>
</html>

Concise marking guide

  1. Creates the correct div and id.
  2. Uses the correct width and height.
  3. Uses the correct background color.
  4. Uses absolute positioning.
  5. Places the object correctly.
  6. Can explain which measurement controls each direction.
  7. Completes one independent bonus object.
