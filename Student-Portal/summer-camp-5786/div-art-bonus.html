DIV Art: Bonus Game Projects

You already know how DIV Art works. Now use it. Copy the HTML when you want, build the CSS yourself, and turn simple boxes into game art.

← Main DIV Art Lesson

Bonus Mission

Important: Your picture does NOT need to match perfectly. If yours looks good, works, and you understand the code, that is better than copying every pixel.

For these projects, the HTML is supplied because the challenge is mainly CSS. Start with the biggest DIV, then add one part at a time.

  1. Look at the target.
  2. Copy the starter HTML.
  3. Build the CSS yourself.
  4. Save with Ctrl + S.
  5. Refresh with Ctrl + R.
  6. Change something and make it yours.
Core tools: width, height, background-color, position: absolute, left, top, IDs and classes.

You may also use border-radius when you want a circle or softer corners. Keep it simple.

Project 1

Retro Arcade Machine

Support level: ★★★ lots of help

Target idea

Boxes first. Circles only for the joystick and buttons.

Your mission

Build an arcade cabinet with a screen, controls and two feet.

Use it in a game: Make it a clickable arcade machine, a level selector, a shop object, or something the player walks up to before starting a mini-game.

Suggested sizes

  • Scene: about 600 × 420
  • Machine: about 240 × 300
  • Screen: about 160 × 100
  • Control panel: about 200 × 65
  • Buttons: about 28 × 28
  • Feet: about 50 × 60

You choose the left and top positions.

Colour ideas

midnightblue purple deepskyblue crimson gold lime

Copy the HTML

<h1>Arcade Machine</h1>

<div id="scene">

    <div id="machine"></div>
    <div id="screen"></div>
    <div id="controlPanel"></div>

    <div id="joystickStick"></div>
    <div id="joystickTop"></div>

    <div id="button1" class="gameButton"></div>
    <div id="button2" class="gameButton"></div>

    <div id="foot1" class="foot"></div>
    <div id="foot2" class="foot"></div>

</div>
Circle hint: same width + same height + border-radius: 50%;
Make it yours: Add a coin slot, a third button, a game title, different colours, or a glowing power light.
Project 2

Road Racer Car

Support level: ★★ some help

Target idea

Your mission

Build a top-down racing car that could become the player in Road Racer.

Use it in a game: Put the whole car inside one player DIV later and move it left and right with JavaScript. Make another colour for enemy traffic.

Parts you need

  • car body
  • window
  • 4 wheels using one class
  • 2 headlights using one class

Only a few size clues

  • Car body: roughly 90 × 180
  • Wheels should be narrow rectangles
  • The window should fit inside the body

Colour ideas

crimson black lightblue gold

Copy the HTML

<h1>Road Racer Car</h1>

<div id="scene">

    <div id="carBody"></div>
    <div id="window"></div>

    <div id="wheel1" class="wheel"></div>
    <div id="wheel2" class="wheel"></div>
    <div id="wheel3" class="wheel"></div>
    <div id="wheel4" class="wheel"></div>

    <div id="light1" class="light"></div>
    <div id="light2" class="light"></div>

</div>
Class challenge: Put the shared wheel CSS in .wheel. Use the IDs only for their different positions.
Bonus: Add a spoiler, racing stripe, number plate or second enemy car.
Project 3

Treasure Chest

Support level: ★★ less help

Target idea

Your mission

Build a game reward chest using mostly rectangles.

Use it in a game: The player could collide with it to earn points, unlock a level, reveal an item, or make the chest change colour when opened.

Build these parts

  • main box
  • lid
  • gold strip
  • lock
  • optional shadow
The lid can still be almost a rectangle. Try rounding only the top corners if you want.

Bonus: Make an “open” version by moving the lid upward. You can later switch between closed and open with JavaScript.

Game Shop

Support level: ★ getting independent

Target idea

SHOP

Your mission

Make a simple building that looks like somewhere your player could visit.

Use it in a game: Make the shop a collision zone. When the player reaches the door, JavaScript could show “Welcome to the shop!” or display an upgrade menu.

You decide the sizes

Try to include:

No measurements this time. Use the target only as a guide.

Project 5

Player Spaceship

Support level: ★ mostly independent

Target idea

Your mission

Create a spaceship from simple DIVs. It does not have to look like this one.

Use it in a game: This can become the actual player. Later you can move it with arrow keys and make enemy DIVs or falling objects.

Possible parts

  • body
  • 2 wings
  • window
  • engine flame
  • optional stars
If a curve starts becoming annoying, stop. A square-looking spaceship is completely fine. Good DIV Art does not need complicated shapes.

Copy the HTML

<h1>Player Spaceship</h1>

<div id="scene">

    <div id="shipBody"></div>

    <div id="wing1" class="wing"></div>
    <div id="wing2" class="wing"></div>

    <div id="shipWindow"></div>
    <div id="flame"></div>

    <div id="star1" class="star"></div>
    <div id="star2" class="star"></div>
    <div id="star3" class="star"></div>

</div>
Bonus: Make a second spaceship as an enemy. Change its colours and shape so it is clearly different.
Project 6

Mini Game Arena

Final challenge: build the beginning of a real game

Target idea

Your mission

Build a tiny level using DIVs: a player, walls, collectibles and a goal.

This IS the start of a game: JavaScript can later move #player, detect collisions with .wall, collect .coin DIVs, and win when the player reaches #goal.

Rules

  • At least 3 walls
  • At least 3 coins
  • 1 player
  • 1 goal
  • Use a class for repeated walls
  • Use a class for repeated coins

Design your own level. Do not copy the target layout exactly.

Copy the HTML

<h1>Mini Game Arena</h1>

<div id="game">

    <div id="player"></div>

    <div id="wall1" class="wall"></div>
    <div id="wall2" class="wall"></div>
    <div id="wall3" class="wall"></div>

    <div id="coin1" class="coin"></div>
    <div id="coin2" class="coin"></div>
    <div id="coin3" class="coin"></div>

    <div id="goal"></div>

</div>
Important: Give #game a width and height and use position: relative;. Then your game objects can use position: absolute;.
Super bonus: Add a danger zone, second room, key, door, extra coins, checkpoint, sign, shop or anything else made from DIVs.

Fast Finisher: Turn Art Into Game Pieces

Pick one thing you built and prepare it for JavaScript.

  • Car → player for Road Racer
  • Spaceship → player for a space game
  • Chest → collectible or reward
  • Shop → place the player can enter
  • Arcade machine → level selector or mini-game entrance
  • Arena → movement + collision game
Best challenge: Build something new without a target picture. If another student can tell what it is, your DIV Art worked.
