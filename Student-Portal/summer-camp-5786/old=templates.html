RBS Code Templates

Build Faster. Understand the Code.

Templates are starting points, not magic. Choose one you understand, copy it, then change it into your own project.

Rule: every template shows the lessons and skills it uses. If you see something unfamiliar, open the skill list and review it before treating the code as your own.

1. Cool Cars Website

A tiny real-looking website: navbar, hero image, heading and intro.

HTML 1–2CSS 1–2
Code
<!DOCTYPE html>
<html>
<head>
<style>
body {
    margin: 0;
    font-family: Arial;
    text-align: center;
    background-color: #eef2ff;
}

nav {
    background-color: navy;
    padding: 15px;
}

.nav-link {
    color: white;
    margin: 15px;
    text-decoration: none;
}

.hero-image {
    width: 80%;
    margin-top: 25px;
    border-radius: 15px;
}
</style>
</head>
<body>
<nav>
    <a class="nav-link" href="#">HOME</a>
    <a class="nav-link" href="#">CARS</a>
    <a class="nav-link" href="#">ABOUT</a>
</nav>

<img class="hero-image" src="../images/8.png">
<h1>Cool Cars</h1>
<p>My favourite cars and racing projects.</p>
</body>
</html>
