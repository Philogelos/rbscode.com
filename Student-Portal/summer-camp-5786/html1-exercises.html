HTML 1 Quick Reference / Template
<h1>...</h1> = main heading
<p>...</p> = paragraph / normal text
<button>...</button> = button
<body> = visible page content
<head> = information about the page
<!DOCTYPE html>
<html lang="en">
<head>
    <title>My Page</title>
</head>
<body>

    <h1>My Game</h1>
    <p>Welcome to my game!</p>
    <button>PLAY</button>

</body>
</html>
