MY FIRST WEBSITE TOOLBOX

HTML + CSS quick reference - find the tool you need and use it

You do not need to memorize everything. Know what the tools do and where to find them.

HTML - What Goes on the Page?

<html>
Container around the whole page.
<head>
Browser information, usually not visible.
<title>
Text on the browser tab.
<style>
Write CSS inside the HTML file.
<body>
Everything visible on the page.
<h1>...<h6>
Headings. h1 is most important.
<p>
Paragraph text.
<br>
New line.
<button>
Clickable button.
<a href="...">
Link. href = where it goes.
<img src="...">
Image. src = where it comes from.
<div>
General-purpose box.

Named website boxes

<header>
Top/header box.
<nav>
Box for navigation links.
<main>
Main page-content box.
<section>
Box for one topic/section.
<footer>
Bottom/footer box.
class
Reusable name for CSS.
id
Name for one special element.
Think:
header/nav/main/section/footer are meaningful boxes, similar to div.

CSS 1 - Make It Look Good

color
Text colour.
background-color
Background colour.
width
Width.
height
Height.
font-size
Text size.
font-family
Font.
font-weight
Normal / bold.
text-align
Left / center / right.
border-width
Border thickness.
border-style
Usually solid.
border-color
Border colour.
border-radius
Rounded corners.

Selectors

h1 { }
Style every h1.
.card { }
Style every element with class="card".
#score { }
Style the element with id="score".

CSS 2 - Space + Website Skills

padding
Space inside the element.
margin
Space outside the element.
-top / -right / -bottom / -left
Change one side only.
margin: auto
Center a box that has a width.
margin: 0
Remove margin, often from body.
width: 80%
Percentage of available width.
text-align: center
Center text/content inside.
text-decoration: none
Remove link underline.
cursor: pointer
Hand cursor for clickable items.
padding: 10px 20px 30px 40px; /* top, right, bottom, left */ margin: 20px auto; /* vertical space + centered box */
Memory: Padding = inside. Margin = outside. margin: auto centers the box. text-align: center centers what is inside.

CSS 3 POWER TOOLS

Useful layout skills for better websites and simple games

Display

display: block
Own line. div is block by default.
display: inline
Stays in the line with text.
display: inline-block
Sits beside others but can have width/height.
display: none
Completely hides an element.

Flexbox - Easy Rows and Columns

display: flex
Turn a box into a flex layout.
gap
Space between flex items.
flex-direction
row = side by side; column = top to bottom.
justify-content
Move items along the main direction.
align-items
Line items up across the other direction.
flex-wrap: wrap
Move items to a new row when needed.
.cards { display: flex; gap: 20px; justify-content: center; flex-wrap: wrap; }

Position - Move Things Precisely

static
Normal/default flow. The element stays where HTML naturally puts it.
relative
Starts in its normal place, then left/top/right/bottom shift it relative to that place.
absolute
Leaves normal flow and uses exact coordinates. Usually measured from a positioned parent.
.box { position: relative; left: 30px; top: 10px; } .player { position: absolute; left: 50px; top: 200px; }
Quick position review: static = normal place. relative = normal place + shift. absolute = exact coordinates outside normal flow.

Coordinates

left
Distance from the left.
top
Distance from the top.
right
Distance from the right.
bottom
Distance from the bottom.

One Useful Extra

overflow: hidden
Hide anything that sticks outside a box. Useful for game areas and image cards.

Mini Website Shape

<header>...</header> <nav>...</nav> <main> <section class="card">...</section> </main> <footer>...</footer>
For today: Build with normal HTML flow first. Use Flexbox when you want a row/column layout. Use position when something really needs to move or sit at exact coordinates.
