MY FIRST WEBSITE TOOLBOX

HTML + CSS quick reference · Find the tool you need and use it

You do not need to memorize everything. Know roughly what tools exist, what they do, and where to find them.

HTML · What Goes on the Page?

<html>
The container around the whole HTML page.
<head>
Information for the browser. Usually not visible on the page.
<title>
The name shown on the browser tab.
<style>
A place to write CSS inside the HTML file.
<body>
Everything the visitor can actually see.
<h1> ... <h6>
Headings. h1 is the biggest / most important.
<p>
A paragraph of normal text.
<br>
Moves to a new line.
<button>
A clickable button.
<a href="...">
A link. href says where it goes.
<img src="...">
Shows an image. src says where the image comes from.
<div>
A general-purpose box used to group things together.

Named Website Boxes

<header>
Like a div for the top/header area.
<nav>
Like a div for navigation links.
<main>
Like a div for the main page content.
<section>
Like a div for one clear section/topic.
<footer>
Like a div for the bottom of the page.
class / id
class can be shared. id names one special element.
Remember: header, nav, main, section and footer are basically meaningful website boxes. They help you understand what each part of the page is for.

CSS 1 · Make It Look Good

color
Text colour.
background-color
Background colour.
width
How wide something is.
height
How tall something is.
font-size
Text size.
font-family
The font.
font-weight
Normal or bold.
text-align
Left, center or right.
border-width
Border thickness.
border-style
Usually solid.
border-color
Border colour.
border-radius
Rounded corners.

CSS Selectors

h1 { }
Styles every h1.
.card { }
Styles every element with that class.
#score { }
Styles the element with that ID.

CSS 2 · Space + Real Website Skills

padding
Space inside an element, between the content and its edge.
margin
Space outside an element, separating it from other things.
padding-top/right/bottom/left
Change one side at a time.
margin-top/right/bottom/left
Change one outside side at a time.
padding: 10px 20px 30px 40px; /* top → right → bottom → left */ margin: 20px auto; /* 20px top/bottom + center the box */
margin: auto
Centers a box such as a card when it has a width.
margin: 0
Removes margin. Often useful on body.
width: 80%
Uses a percentage of the available width.
text-align: center
Centers text and inline content inside a box.
text-decoration: none
Useful for removing underlines from navbar links.
cursor: pointer
Shows the hand cursor over something clickable.
CSS 2 memory rule: Padding = inside. Margin = outside. margin: auto centers the box. text-align: center centers what is inside the box.

WEBSITE POWER TOOLS

Useful CSS 3 skills + quick “I want to…” finder

CSS 3 · Display

display: block
Takes its own line. A div is block by default.
display: inline
Stays in the same line as other inline content.
display: inline-block
Can sit beside other elements but still use width and height.
display: none
Completely hides an element. Very useful later with JavaScript.

CSS 3 · Flexbox

.cards { display: flex; gap: 20px; justify-content: center; align-items: center; flex-wrap: wrap; }
display: flex
Makes it easy to arrange things in a row or column.
gap
Space between flex items.
justify-content
Moves items along the main direction. center and space-between are common.
align-items
Lines items up across the other direction.
flex-direction
row = side by side. column = top to bottom.
flex-wrap: wrap
Lets items move onto another row when space runs out.

CSS 3 · Position

position: static — normal/default position
Elements normally appear in the regular HTML flow: one thing after another. This is the default.
position: relative — move from where it normally would be
The element keeps its normal place in the page layout, but now you can use left, right, top and bottom to shift it relative to its normal/static position.
.box { position: relative; left: 30px; top: 10px; }
position: absolute — exact coordinates
The element leaves the normal page flow, so other elements act as if it is not taking up that space. You can place it exactly with left, top, right or bottom. If its parent has position: relative, the coordinates are measured from that parent.
.game { position: relative; width: 600px; height: 350px; } .player { position: absolute; left: 50px; top: 200px; }
Position memory:
static = stay in the normal flow.
relative = start from your normal place, then shift.
absolute = leave normal flow and use exact coordinates.

For normal websites, use regular flow / Flexbox most of the time. For games, absolute is extremely useful for players, enemies and coins.

Other Useful Tools

overflow: hidden
Hides anything that sticks outside a box. Useful for game areas and image cards.
box-shadow (bonus)
Adds a shadow behind a box.
linear-gradient(...) (bonus)
Changes smoothly from one colour to another.
100vh (bonus)
100% of the visible browser height.

I Want To…

Make text bigger → font-size
Make text bold → font-weight
Change text colour → color
Change a background → background-color
Round the corners → border-radius
Add inside breathing room → padding
Add space outside → margin
Center a card → margin: auto
Center text inside → text-align: center
Make width flexible → width: 80%
Remove link underline → text-decoration: none
Put items side by side → display: flex
Add space between flex items → gap
Hide something → display: none
Move from normal position → position: relative
Use exact X/Y coordinates → position: absolute

Before You Say “I’m Stuck”

□ Did I save the file?
□ Did I refresh the browser?
□ Did I spell the property/tag correctly?
□ Did I add the CSS semicolon ;?
□ Did I close the CSS rule with }?
□ Does a class start with . in CSS?
□ Does an ID start with # in CSS?
□ Is the image path correct?
