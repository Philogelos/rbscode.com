סטודיו לציור בעזרת DIV

בונים רובוטים, טירות ותמונות בעזרת קופסאות HTML פשוטות ו־CSS.

מומלץ להקליד קוד קצר. כשההקלדה מעכבת, אפשר להשתמש בכפתור ההעתקה.

מילים חשובות

מילון קצר

  • width — רוחב
  • height — גובה
  • background-color — צבע רקע
  • position — מיקום
  • absolute — מיקום מדויק
  • left / right — שמאל / ימין
  • top / bottom — למעלה / למטה
  • ID — שם מיוחד לאלמנט אחד
  • class — שם משותף לכמה אלמנטים
  • border-radius — עיגול פינות

הכלל בכל שלב

  1. מוסיפים רק את הקוד החדש.
  2. לוחצים Ctrl + S.
  3. חוזרים לדפדפן.
  4. לוחצים Ctrl + R.
  5. בודקים מה השתנה.
הדגמה 1

יוצרים מלבן ראשון

צרו תיקייה בשם div-art וקובץ בשם demo-1.html.

<!DOCTYPE html>
<html>
<head>
    <title>My First Shape</title>
    <style>
        #shape {
            width: 200px;
            height: 100px;
            background-color: blue;
        }
    </style>
</head>
<body>
    <div id="shape"></div>
</body>
</html>

<div> הוא קופסה ריקה. ה־ID נותן לה שם. width קובע רוחב, height קובע גובה, ו־background-color קובע צבע.

ניסויים

ריבוע:

width: 150px;
height: 150px;

מלבן גבוה:

width: 80px;
height: 220px;
הדגמה 2

מזיזים את הצורה

הוסיפו בתוך חוק ה־#shape:

position: absolute;
left: 300px;
top: 150px;

left מודד מצד שמאל. top מודד מלמעלה.

משתמשים בדרך כלל ב־left או right, וב־top או bottom.

אותן עיניים עם class מסודר

את מה שמשותף שמים ב־class. את מה ששונה שמים ב־ID.

<div id="eye1" class="eye"></div>
<div id="eye2" class="eye"></div>

.eye {
    width: 30px;
    height: 30px;
    background-color: yellow;
    position: absolute;
    top: 120px;
}

#eye1 { left: 445px; }
#eye2 { left: 510px; }
class מכיל את המשותף. ID מכיל את ההבדל.

אתגר טירה קטנה

אפשר להעתיק את ה־HTML. את ה־CSS כותבים לבד.

<h1>Mini Castle</h1>
<div id="scene">
    <div id="grass"></div>
    <div id="castle"></div>
    <div id="door"></div>
    <div id="flagPole"></div>
    <div id="flag"></div>
</div>

איך border-radius עובד?

ערך אחד מעגל את כל הפינות:

border-radius: 20px;

ארבעה ערכים הולכים לפי הסדר: שמאל־עליון, ימין־עליון, ימין־תחתון, שמאל־תחתון.

border-radius: 30px 10px 40px 0;

כתיבה ארוכה — longhand

border-top-left-radius: 30px;
border-top-right-radius: 10px;
border-bottom-right-radius: 40px;
border-bottom-left-radius: 0;

שתי הצורות כותבות את אותו הדבר.

איך קימור המטרייה עובד?

border-radius: 50% 50% 0 0;
  • שמאל־עליון: מעוגל
  • ימין־עליון: מעוגל
  • ימין־תחתון: ישר
  • שמאל־תחתון: ישר

אותו דבר בכתיבה ארוכה:

border-top-left-radius: 50%;
border-top-right-radius: 50%;
border-bottom-right-radius: 0;
border-bottom-left-radius: 0;

טעויות נפוצות

  • לא מופיע כלום: בדקו שה־ID מתאים ל־CSS.
  • הצורה לא זזה: בדקו position: absolute.
  • class מתחיל בנקודה, למשל .eye.
  • ID מתחיל בסולמית, למשל #eye1.
  • לא השתנה כלום: שמרו ורעננו.
DIV אחד הוא צורה אחת. הרבה צורות יכולות להפוך לעולם שלם.
